# Roast Your Own Agent

> My agent ran five tool calls, read none of the results, and confidently announced: 'Done — see above.' There was nothing above.

`main.ts` holds the entry line as a constant, validates it against the bounty rules (a single line, 1–140 characters, no newline or control characters), and writes it — with no trailing newline — to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR`.
